# Daphne Toolkit

面向 **Wizardry Variants Daphne** 的简易修改工具，提供属性调整、战斗倍速和技能无消耗，支持多语言。属于个人学习与实验项目，功能和适配范围有限。

## 使用初衷

不提倡频繁使用或长期依赖修改。主要用于减少重复、缺乏变化的刷本过程带来的时间成本，或协助通过难度过高、影响体验的章节任务。

可根据需要配合其他作者的自动化脚本使用；本工具本身不包含自动刷本功能，与其他脚本的兼容性需自行确认。

## 功能

- 调整 12 项战斗属性，支持统一设置或分别设置。
- 战斗倍速：2–20 倍。
- 技能无消耗：SP／MP 消耗设为 0，可关闭并还原。
- 语言：英文、日文、简体中文、繁体中文（台湾／香港）。

## 下载与使用

适用于 Windows 10／11 64 位电脑版游戏。前往本仓库的 [Releases](https://github.com/lin123p/daphne-toolkit/releases/latest) 下载 `Daphne.exe`，无需安装 Python。

1. 正常关闭游戏。
2. 运行 `Daphne.exe`，设置选项并点击“应用修改”。
3. 重新启动游戏，使修改生效。

应用或还原修改前均需关闭游戏；仅打开修改器不要求退出游戏。属性滑块中，0 表示原始值，1–10 对应原始战斗系数的 10–100 倍，并不保证最终伤害按同样倍率变化。

“恢复默认”用于恢复所选范围的属性设置；战斗倍速设为 2、关闭“技能无消耗”可分别还原对应功能，最后应用修改。游戏更新后可能需要重新适配。
